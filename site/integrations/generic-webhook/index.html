Integrations / Generic

Any JSON Webhook notifications in Microsoft Teams

Datadog, custom scripts, home-grown CI — anything that POSTs JSON becomes a Teams card. Per My Last Webhook normalizes Generic events into rich Adaptive Cards and posts them to a Teams channel, a person's DM, or a webhook — the successor to Office 365 Connectors.

Install for Teams Read the guide

How it works

  1. Generic POSTs a webhook to your private ingest URL when a build runs.
  2. We normalize it — the same card format as every other platform.
  3. The card lands in your chosen Teams destination, with routing and noise controls applied.

Set up in minutes

Create a subscription in the app (platform: Generic), copy its ingest URL, then:

1

Create a subscription with platform generic.

2

Add a field mapping (which JSON paths map to title / status / link).

3

Point your tool's webhook at the ingest URL.

4

Fire an event → card lands.

See it instantly

Don't want to wait for a build? Hit Test on the subscription — a card lands immediately. Full steps in the platform reference.
